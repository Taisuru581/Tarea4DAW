DECIDIR Y RESPONDER

Control de flujo y errores

{ }

Un programa toma decisiones según sus datos. Si algo falla, puede explicar el problema y permitir que lo corrijas.

if...else
Ejecuta un bloque si la condición es verdadera y otro si es falsa. Aquí decide si la edad permite una inscripción de práctica.
switch
Compara un valor con varios casos. Aquí el curso elegido determina el mensaje; break termina cada caso.
try / catch / throw
try intenta ejecutar; throw lanza un problema; catch lo captura para mostrarlo.
Objetos Error
Describen errores con propiedades como name y message. RangeError identifica un valor fuera del rango permitido.

REPETIR CON INTENCIÓN

Bucles e iteración

↻

Un bucle repite instrucciones. La posición de su condición cambia cuándo comienza y cuándo termina.

for
Reúne inicio, condición y actualización. Es útil cuando conoces cuántas repeticiones necesitas.
while
Comprueba la condición antes de cada vuelta. Si comienza siendo falsa, no ejecuta ninguna.
do...while
Comprueba la condición después del bloque: ejecuta al menos una vuelta.

RELACIONAR LOS DATOS

Expresiones y operadores

+=

Una expresión produce un valor. Los operadores permiten asignar datos, calcular y combinar condiciones.

Asignación
= guarda un valor; += suma y reasigna. let total = a; total += b; termina con a + b.
Comparación
=== compara valor y tipo; == permite conversión. !==, >, <, >= y <= también producen booleanos.
Aritméticos
+, -, *, /, % y ** suman, restan, multiplican, dividen, calculan el resto y elevan a una potencia.
Lógicos
Con operandos booleanos, && exige ambas condiciones, || al menos una y ! invierte el valor.

MEDIR Y UBICAR EN EL TIEMPO

Números y fechas

123

JavaScript incluye herramientas para convertir números, hacer operaciones matemáticas y representar fechas.

Number
Number(texto) convierte un texto. Number.isFinite() verifica el resultado y toFixed(2) devuelve un texto con dos decimales.
Math
Ofrece operaciones como round, floor, ceil, abs y sqrt. Se usa directamente, sin new.
Date
new Date() crea una fecha. Sus métodos permiten consultar año, mes y día. Los meses de su constructor numérico van de 0 a 11.

DAR FORMA A LAS PALABRAS

Formateo de texto

Aa

Las cadenas guardan texto. Podemos combinarlo con datos, limpiarlo y transformarlo sin modificar la cadena original.

Cadenas literales
Se escriben con comillas simples, dobles o acentos graves. Una plantilla como `Hola, ${nombre}` inserta el valor de una expresión.
String y sus métodos
String(valor) convierte a texto. trim(), toUpperCase(), toLowerCase(), includes() y slice() permiten trabajarlo.

ORGANIZAR MUCHOS VALORES

Colecciones indexadas

[ ]

Una colección indexada permite acceder a sus elementos por posición. El primer índice es 0.

Arreglos: Array
Pueden crecer y contener distintos tipos. Aquí usamos push(), map(), filter() y reduce() con una lista de números.
Arreglos tipados: Uint8Array
Son vistas de datos binarios con un tipo numérico concreto. Esta vista almacena enteros sin signo de 8 bits: de 0 a 255; no es un Array normal.
